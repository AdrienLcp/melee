# 37 — A challenge the scale decides

**To do.** The challenge game (`challenge`) ranks by the host's word. Some
challenges have a measurement instead — cut a vegetable into two halves of the
same weight — and the host should type the measurement, not the placing.

- The host types, per team or seat, the two weights read off a kitchen scale.
- The gap is relative, `|a − b| / (a + b)`, so the team handed the larger
  vegetable is not penalised; the closest finishes first, and the existing
  3 / 2 / 1 placing pays it.
- The reveal on the wall shows each team's two weights and its gap.
- Generalise only if a second measured challenge shows up (a distance, a time):
  until then it is the halves of one thing, not a measurement framework.
