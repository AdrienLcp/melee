# h — Later

After the December rehearsal, in no fixed order. Each becomes a step file of
its own when it is taken.

- **French cities** — *Place-moi Rennes* on a map of France (conic conformal in
  the same `d3-geo` pipeline), scored by the km tiers of step d. A second
  `worldmap` question kind with a France frame, not a new game.
- **More modes** — *solo*: one designated seat per team in turn; *duel*: two
  seats head to head. Each is a roster rule beside step c's.
- **More board strategies** — Gamenight's options b (race to the line, track
  sized to the evening) and c (case values scaled to the planned rounds, a
  final race if nobody finished), and catch-up: points by rank, bonus cases
  favouring trailing teams. One file each in `core/board/`.
- **The booby-prize trophy** — the evening's finale: an individual award from
  the seat results the shell kept under the team scores (most wrong, slowest,
  farthest on the map).
- **Teams only with no phone at all** — answers aloud, judged by the host
  through `host.judge` in every game.
- **Screen-only fallback** — an evening with no host phone; re-decide its shape
  first (Gamenight's step 9).
- **Archive Gamenight** — once d and e ship: redirect `gamenight.adrienlcp.com`
  to Taverla, archive the repository on GitHub, delete its Worker.
- **The rename**, if decided (decision 1) — the checklist is in
  [`open-decisions.md`](open-decisions.md).
